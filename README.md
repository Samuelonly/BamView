# BamView

**看一眼就走。**

BamView 是一款为 macOS 打造的图片查看器：从 Finder 打开图片，窗口按图片比例出现，看完即可关闭。不打断手头的事，也不在系统里留下痕迹。

## 核心能力

- **单图查看** — 窗口与图片等比，默认铺满、无黑边；滚轮翻页、胶卷、缩放平移
- **网格浏览** — 视图复用与可视区虚拟化，大文件夹不卡顿
- **排序与呈现** — 日期 / 名称 / 大小，缩略图 / 自适应 / 瀑布流
- **轻量设置** — 默认打开方式、支持格式、快捷键、检查更新

## 支持格式

- JPEG / PNG / TIFF / BMP / GIF / HEIC / WebP（含动图逐帧播放）/ AVIF
- JPEG XL（仅 macOS 26 及以上系统支持）
- PSD / PSB（合成预览，不支持图层浏览与编辑）
- RAW 走系统 ImageIO：DNG、ARW 已实测

## 系统要求

- Apple Silicon（M 系列芯片）
- macOS 15 / 26 / 27

## 已知限制

- 单图解码长边封顶 4096px，超过 100% 后为插值放大，不是原始像素。
- PSD / PSB 仅渲染合成预览，不支持图层浏览与编辑。
- RAW 已实测 DNG 与 ARW；CR3 / NEF / RAF 的系统解码回归安排在 1.1。
- JPEG XL 仅在 macOS 26 及以上系统出现。
- 超大文件首次打开耗时随像素数线性增长；目录扫描为同步列目录。
